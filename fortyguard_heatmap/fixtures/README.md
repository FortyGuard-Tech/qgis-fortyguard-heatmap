# Demo fixtures (SYNTHETIC)

SYNTHETIC DEMO DATA generated by scripts/make_demo_fixtures.py - NOT a FortyGuard analysis.

* `demo_aoi.geojson` - sample area (EPSG:4326), same rectangle as the public API docs example.
* `demo_result_single_hour.geojson` - 182 tiles with `properties.temperature` (one NULL on purpose).
* `demo_result_daily.geojson` - 182 tiles with `average_temperature`, `min_temperature`, `max_temperature`.

Values are invented with a smooth function and never came from the FortyGuard API.
Regenerate with `python3 scripts/make_demo_fixtures.py`.
