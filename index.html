FortyGuard Temperature Intelligence Layer

Version 0.5.4 · QGIS 3.34 or newer · updated 2026-11-09

Hyper-local temperature intelligence for a selected site or asset, as styled QGIS layers: temperature (°C), exceedance and persistence hours above a threshold, and peak temperature time, from the FortyGuard Temperature API.

Install from inside QGIS (recommended)

  1. Open QGIS, then Plugins › Manage and Install Plugins…
  2. Click Settings in the left column.
  3. Under Plugin Repositories click Add…
  4. Name: FortyGuard — URL: copy the address below, then click OK.
  5. Go back to All, search for FortyGuard and click Install Plugin.
https://fortyguard-tech.github.io/qgis-fortyguard-heatmap/plugins.xml

QGIS checks this repository for updates like any other, so new versions appear in the Plugin Manager automatically.

Or install the ZIP

Download the package and use Plugins › Manage and Install Plugins… › Install from ZIP.

Download fortyguard_heatmap.0.5.4.zip
