Download FortyGuard for QGIS

The FortyGuard Temperature Intelligence Layer plugin adds FortyGuard temperature heatmaps to your own QGIS projects. Select an area, pick a date, and get a styled layer with tile temperatures in °C.

Install in QGIS

FortyGuard Temperature Intelligence Layer is listed in the official QGIS Plugin Repository. The ZIP download above is the same package, for offline installs.

  1. Open QGIS and choose Plugins ▸ Manage and Install Plugins…
  2. In the All tab search for FortyGuard, select FortyGuard Temperature Intelligence Layer and click Install Plugin. (Offline alternative: Install from ZIP with the file above.)
  3. In the Installed tab make sure FortyGuard Temperature Intelligence Layer is ticked. A FortyGuard button appears in the toolbar.
  4. Click the button, paste your own FortyGuard API key, and click Check key and credits.
  5. Select exactly one polygon on the map (United States), choose a date at least a week ago and the resolution, then click Generate Heatmap.

Your API key

The plugin works with your own FortyGuard API key. Get one on the FortyGuard API plans page. The key is sent only to the FortyGuard API, is kept in memory while QGIS runs, and can optionally be saved in the encrypted QGIS authentication database. Every completed heatmap request consumes credits from your plan (documented: 3,500 credits on API Basic/Startup, 4,220 on API Premium; rejected and failed tasks are free, a completed job with no tiles is charged). Coverage is documented as the United States, and data for the most recent days (about one week) is usually not available yet. The plugin checks the area, the dates and duplicate requests before it submits anything that costs credits.

What you get

  • GeoJSON tiles saved in Documents/FortyGuard Heatmaps and added as a styled vector layer.
  • Four analyses, each one API request: Temperature/Snapshot (°C), Exceedance (hours above a threshold), Persistence (longest continuous run) and Peak temperature time (hour of day, UTC).
  • Single hour, range of hours, single day, range of days and calendar month; 60, 80 or 100 m resolution.
  • Mean, minimum or maximum tile temperature for daily outputs, area statistics from the API.
  • Pre-checks before every paid request: coverage, area size, recent dates, duplicates.
  • Non-blocking status polling with Stop Waiting and Check Again.
  • An optional Demo Mode with clearly labelled synthetic data for offline testing.
